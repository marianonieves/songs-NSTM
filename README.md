# NSTM — Cancionero

Repositorio de canciones para ensayo y vivo de NSTM.

## Organización

- `covers/`: versiones de otros artistas.
- `propias/`: canciones originales de NSTM.

## Formato de cada canción

Cada tema se guarda como un archivo `.txt` compacto y fácil de leer mientras se toca:

- título y artista o versión;
- tono y afinación, cuando corresponda;
- partes claramente marcadas: `[INTRO]`, `[VERSO]`, `[PRE]`, `[ESTRIBILLO]`, `[PUENTE]`, `[OUTRO]`;
- acordes ubicados sobre la letra cuando sea necesario;
- progresiones resumidas por sección cuando resulte más práctico;
- repeticiones indicadas como `x2`, `x4`, etc.;
- notas breves de entrada, corte o dinámica.

## Nombres de archivo

Usar minúsculas y guiones, por ejemplo:

- `covers/pearl-jam-better-man.txt`
- `propias/set-me-free.txt`
